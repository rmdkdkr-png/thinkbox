# SVC MotM 램 지도 — 원버튼 엔진이 실측으로 확정한 자리들

> SP 방, 2026-09-02. 전부 실측·엔진 실사용 중(v3.49). CPU 주소 = CPUExRAM 오프셋.
> 살아 있는 소스: ss2-sp-core `src/svcsp.c` (낡은 사본 주의 — traps.md 참조).
> KOF R-2 등 다른 게임 이식 시 이 표가 「무엇을 찾아야 하는가」의 견본이다.

## 1층 — 엔진 구동에 필수

| 기호 | 오프셋 | 쓰임 · 주의 |
|---|---|---|
| CHAR1 / CHAR2 | `0x08A0` / `0x08C0` | 전투 중 판별 4종 세트의 일부 |
| STYLE / TIMER | `0x08BE` / `0x08EE` | 〃 |
| FACE | `0x092C` bit7 | 좌우 반전. **좌표 비교로 반전을 판정하지 말 것** (6번 오판 전과) |
| Y1 | `0x0930` | 공중 판정 |
| BANK | `0x09AD` | 동작 뱅크. 대기값 255. **재시도 보조용 — 신원 확정엔 부족** |
| **ACT** | **`0x0968`** | **동작번호 — 판정의 중심.** 뱅크가 같은 기술을 가른다(황물기 157/독물기 168). 캐릭터별 + 진행 단계별(가일 소닉붐 = 2/37/38/48) |
| ANIM P/K | `0x0C7E` / `0x0C7F` | 행동가능 근사(둘 다 ≥6). 2프레임에 1씩, 포화형 |
| HOLDCNT P/K | `0x0C76` / `0x0C77` | 버튼 쥠 카운터 — **강약 주입**이 여기 쓴다. 놓으면 리셋 |
| DIRHIST 링 | `0x0CB8`~`0x0CCE` (2바이트 간격 24칸) | 방향 이력 — **링 주입**으로 발동 9→3프레임 |
| RING_TOP | `0x0CC8` | 링 최신 위치 |
| ROM 강 문턱 | 롬 `0x000D4E` (기본 4) | 강 판정 문턱. 램 홀드카운터를 쓰면 필요 없음 |

## 2층 — 검증 전용

| 기호 | 오프셋 | 쓰임 · 주의 |
|---|---|---|
| REACT | `0x0AC4` | 상대 반응. **255 = 피격 경직** — 「히트」 판정의 잣대 |
| COMBO | `0x0B17` | 콤보 카운터. **표시 타이머가 아니라 진짜 판정** (반증 실험 완료 — g=26~40f 두 대는 카운터 1) |
| HP(표시) | `0x08CF` | **표시 사본** — 원본 따로 있음 |
| P1 X | `0x0934/5` (16비트) | **표시 사본** — poke 해도 판정 무효(150~330 전 구간 무피해). 거리는 걸어서 만들 것 |

## 판정 사다리 (이 지도의 사용법)

발동 = ACT 진입 프레임 · 히트 = REACT 255 프레임 · 콤보 = COMBO ≥2.
중립 act 집합 `{0,21,22,23,255}` (+기본기 대역 3~9·11~14 — svcsp.c 본문에 박혀 있음).

## 게임 규칙 실측값 (순정 기준)

- 입력 반영 2프레임 지연 · 입력 샘플링 2프레임 주기 → **모든 측정은 위상 2종으로**
- 약/강 버튼 문턱: 1f 무시 · 2~7f 약 · **8f+ 강** (경계 7|8)
- 커맨드 창: 마지막 방향과 같은 프레임은 실패 · +2~+5f 성공 · +6f 만료
- 방향 스텝: 마지막 두 칸 2프레임 필수, 그 앞은 1프레임 가능
- 모으기(가일): 문턱 **30프레임** · 유예 8프레임 (가짜 6f 는 오염된 판정식의 산물이었다)
- 투사체 약/강 = 탄속 차 (+68 vs +90/4프레임급) — **원거리에서만 규명**
