# SS2 그림 글자 삽입 — 처음 보는 사람 기준 (이식소, 2026-09-05)

아트 PNG 한 장을 롬에 넣는 데 필요한 것은 **PNG + 자산 JSON + 도구 하나**뿐이다.

    python3 tools/gfx_insert.py build <아트.png> <gfx-ss2/h_키.json> <롬_in> <롬_out>
    python3 tools/gfx_insert.py verify <gfx-ss2/h_키.json> <롬_a> <롬_b>     # 그 자산 타일만 비교

## 1. 아트 규칙 (어기면 좌표를 대며 멈춘다)
| 규칙 | 값 |
|---|---|
| 캔버스 | 자산 카드의 «칸 × 8» — 예: 승부 72×96, 자아 당당히 24×96, 이름판 80×32, 헤더 96×24 |
| 색 | 칸(8×8)마다 **팔레트 하나**, 그 팔레트의 4색만. 색은 자산 카드/JSON `palettes` 에 있다 |
| 투명 | 알파 0 **또는 자홍(#ff00ff)**. 원본이 투명이던 자리는 투명이어야 한다(배경이 비쳐야 할 자리다) |
| 예산 | 고유 타일 ≤ 카드의 «예산». 넘으면 도구가 멈춘다 — 닮은 칸을 같은 그림으로 맞추거나 `space-and-scope.md` 에 새 자리를 등록하고 JSON 을 늘린다 |
| 반전 | 원본이 좌우/상하 반전으로 같은 타일을 재사용하는 칸이 있다. 새 그림이 그 관계를 깨면 도구가 그 좌표를 알려 준다(`--merge` 로 첫 칸 그림에 통일할 수 있지만 그 칸은 원본과 달라진다) |

PNG 는 8비트 RGB/RGBA/팔레트 다 받는다. **4배로 뽑아 둔 `p_*.png`/`h_*.png` 는 보기용이다 — 넣을 때는 1배로 줄여서 준다.**

## 2. 무엇이 어디에 써지나
JSON 의 `tiles` 에 «타일 번호 → 롬 주소»가 있고, 도구는 **그 주소에만** 16바이트씩 쓴다(제자리 덮어쓰기). `blank`/`notfound` 타일은 공용일 수 있어 건드리지 않는다. 지도(평면1 스크롤)는 손대지 않으므로 글자의 «자리·크기»는 바뀌지 않는다.
이식소가 쓰는 범위는 `space-and-scope.md` 「SS2 자리 배정표」에 등록돼 있다. 새 자리가 필요하면 거기에 먼저 적는다.

## 3. 검증 — 왕복부터
새 아트를 넣기 전에 **현행 한패 그림을 그대로 왕복**시켜 도구가 손을 안 대는지 본다. 8건 통과 기록(2026-09-05):
```
승부 41자리/41고유 · 자아당당히 25/25 · 1회전 36/35 · 수라나찰 47/46
한판!! 27/27 · 완승 28/28 · 승부결정 29/29 · 이름판(아수라) 20/20   → 전부 타일 바이트 0 차이
```
그 다음 화면으로 본다. **⚠ 화면 대조에는 함정이 둘 있다:**
1. **`.flash` 세이브** — 롬 파일 옆에 저장 파일이 생긴다. 롬이 바뀌지 않아도 저장 상태가 다르면 화면이 달라진다. 비교하는 두 롬은 **각각 새 폴더에 복사해** 돌린다.
2. **긴 대본은 결정적이지 않다** — 같은 롬·같은 대본을 두 번 돌려도 대전이 길어지면 화면이 갈린다(실측: 라운드 시작 배너 f520 은 0 화소 차이, 승부 f700 은 1321, KO 뒤 f1020 은 10926). 화면 대조는 **입력 없이 빨리 닿는 자리**에서 하고, 늦은 화면은 `!save` 상태를 만들어 그 상태에서 캡처한다.

## 5. 칠할 수 있는 칸 (2026-09-05 추가 — 반드시 읽을 것)
배너의 «칸→타일» 지도는 **롬 표가 아니라 게임 코드가 VRAM 에 쓴다**(stride 2 로 롬 전역 검색 실패). 그래서 칸에 타일을 새로 배정할 수 없고, **원본이 잉크를 놓은 칸 안에서만** 새 글자를 그려야 한다.
못 그리는 칸의 정체는 «배정 부족»이 아니라 **여러 칸이 같은 빈 타일을 나눠 쓰는 것**이다(1회전 77칸 중 40칸이 색인 0). 거기에 칠하면 화면의 빈 칸이 전부 같이 칠해진다.
`p_<키>_mask.png`(칸당 16px) — **흰색** 자유 · **주황** 다른 칸과 공유(같이 바뀜) · **검정** 공용 빈 타일(비워 둘 것). 자유 칸: 승부 66/108 · 자아 당당히 24/36 · 1회전 37/77 · 수라나찰 47/80 · 한판!! 34/96 · 완승 32/96 · 승부 결정 48/96 · 이름판 34/90.
원본보다 넓게 쓰려면 **코드가 지도를 쓰는 자리**를 찾아 칸에 새 타일 번호를 넣어야 한다(미착수).
