# SS2 촬영·자산 도구 (이식소, 2026-09-05)

## 엔딩·보스 촬영
```
python3 endcap.py <자리> <KO블록수> <표본수>      # → ~/ss2/tmp/end/k<자리>.pkl (12프레임 간격 화면들)
python3 pickshots.py                              # → release_final/endings/*.png + endings.tsv
```
`SS2ROM` 환경변수로 롬을 바꾼다. 기본은 `~/ss2/work_lang/v10/release_final/ss2_v1.0_final.ngc`.

**규칙 셋 — 어기면 헛수고다**
1. **마지막 KO 뒤 포크를 끊는다.** 엔딩 도중 `!poke` 를 계속하면 화면이 굳고 ngprun 이 그대로 죽는다(traps ⑪).
2. **블록 수는 롬마다 다시 찾아야 한다.** 같은 대본이라도 롬이 다르면 컷신 길이가 달라 박자가 밀린다 — 밀리면 최종전을 **져 버린다**(traps ⑬). 9·10·11·12를 돌려 «엔딩에 닿은» 판을 고른다.
3. **장면은 판정기 하나로 고르지 마라**(traps ⑫). `endpick.isend()` 는 «좌우 갈색 체크 테두리 + 가운데 80% 이상 검정»으로 엔딩 글 페이지만 고른다 — 카드·스태프롤·어두운 무대가 전부 걸러진다.

## 그림 자산 뜨기
```
python3 mkasset.py                                # vrdec.V 로 덤프 폴더를 가리키고 build(lab,tag,rows,cols,key,out)
```
`!vram <태그>` 덤프(char 8192·scroll 4096·pal 512)를 읽어 **평면0**의 사각 구역을 자산으로 만든다 —
`<lab>_<키>.json`(칸→타일·팔레트·반전 + 타일별 롬 주소) · 미리보기 · **칠할 수 있는 칸 마스크**.
지도 한 칸 = 2바이트, 타일 = 하위 9비트, 비트9 좌우반전·비트10 상하반전·비트12~15 팔레트.

## 2026-09-05 추가
· `pickfinal.py` — 고친 롬(varC) 기준 고르기. **이 게임의 엔딩은 «한 쪽»이다** — 글이 한 판에 쌓여 가득 차면 곧바로 스태프롤이다. 「편당 2장」은 없다.
· `dlgcap.py <자리>` — 처음부터 9블록까지 24프레임 간격으로 훑어 **대사창 있는 장**을 모은다(난입 대사 찾기용).
· 판정에서 걸린 함정 하나 더: **스태프롤도 «갈색 테두리 + 검은 판»이라 `isend` 를 통과한다.** 창의 앞머리(엔딩 글이 스태프롤보다 먼저 시작한다)만 보고 골라야 한다. 그리고 촬영 창이 이미 엔딩 «한가운데»에서 시작하면 글이 쌓이는 과정을 못 본다 — **창 시작이 표본 10번 이후인 판만 받아들여라**(`runfix.py` 규칙).
